# The pet shows the Claude mark

**Decided by:** the owner.

**What:** the `pet` app draws the Claude spark (`pet/app/Spark.swift`) and calls itself «Mascota de Claude»
(`pet/app/Info.plist`, `pet/app/Text.swift`): the pet is Claude's own mark, floating above every window. Its listing
icon draws a soft asterisk instead (DESIGN.md, Icons), so the marketplace does not present the mark as the mod's. The
README says the project is not affiliated with Anthropic.

**Value weighed:** a third party's trademark in a public repo against what the pet is for. Anthropic could ask for
the mark to be removed; then `Spark.swift` would draw another shape and nothing else would change.

**Rejected:** a shape of the pet's own, such as the icon's asterisk or a spark with longer arms, since the pet would
no longer be the Claude spark.
